## 1. 의사결정 나무 (Decision Tree Regressor) - 회귀

회귀를 위한 의사결정 나무 모델을 사용해 보고, 결과를 확인해 보겠습니다.

특히 max_depth 라고 하는, 나무의 최대 깊이를 다양하게 정의하여 모델의 학습 결과를 그래프를 통해 이해해 보겠습니다.

------

***\*회귀 의사결정 나무를 위한 사이킷런 함수/라이브러리\****

- `from sklearn.tree import DecisionTreeRegressor` : 사이킷런에 구현되어 있는 회귀 의사결정 나무 모델을 불러옵니다.
- `model=DecisionTreeRegressor(max_depth)`: 의사결정 나무 기반 회귀 모델을 정의합니다.
- - `max_depth` : 트리의 최대 깊이
- `model.fit(X, y)`: (X, y) 데이터셋에 대해서 모델을 학습시킵니다.
- `model.predict(X)`: X 데이터에 대해 모델이 예측한 값을 반환합니다.

## ***\*실습\****

1. 회귀를 위한 의사결정 나무 모델을 정의하고, X 데이터에 맞추어 학습시키고 예측값을 반환하는 함수 `DT_Reg()` 를 완성합니다.

- - 모델의 파라미터 `max_depth`를 `m_depth`값으로 설정한 회귀 의사결정 나무 모델을 정의합니다.
  - 정의한 회귀 의사결정 나무 모델을 X 데이터에 맞추어 학습시킵니다.
  - 학습한 모델을 이용하여 `X_test` 데이터에 대한 예측을 수행합니다.

1. 정의한 함수 `DT_Reg()`를 이용하여 `max_depth`가 ***\*1, 5, 20\**** 인 회귀 의사결정 나무 모델로 예측한 결과를 각각 아래와 같이 저장합니다.

- - `y_1` 에는 `max_depth`가 ***\*1\****인 회귀 의사결정 나무 모델의 예측값을 저장합니다.
  - `y_5` 에는 `max_depth`가 ***\*5\****인 회귀 의사결정 나무 모델의 예측값을 저장합니다.
  - `y_20` 에는 `max_depth`가 ***\*20\****인 회귀 의사결정 나무 모델의 예측값을 저장합니다.

1. 실행 버튼을 눌러 다양한 층의 회귀 의사결정 나무 모델의 결과를 확인해 보고, 층의 깊이에 따라 결과가 어떻게 달라지는지 생각해 보세요.

## 2. 의사결정 나무 (Decision Tree Classifier) - 분류

이번 실습에서는 분류 문제 해결을 위해 Iris 데이터를 사용합니다. Iris 데이터는 ***\*꽃받침 길이, 꽃받침 넓이, 꽃잎 길이, 꽃잎 넓이\**** 네 가지 변수와 ***\*세 종류의 붓꽃 클래스\****로 구성되어 있습니다.

iris 데이터에 대해 분류 의사결정 나무 모델을 사용하여 예측 문제를 수행해 보도록 하겠습니다.

------

***\*분류 의사결정 나무를 위한 사이킷런 함수/라이브러리\****

- `from sklearn.tree import DecisionTreeClassifier` : 사이킷런에 구현되어 있는 분류 의사결정 나무 모델을 불러옵니다.
- `model=DecisionTreeClassifier()`: 분류를 위한 의사결정 나무 모델을 정의합니다.
- `model.fit(X, y)`: (X, y) 데이터셋에 대해서 모델을 학습시킵니다.

### ***\*실습\****

1. 데이터를 불러오고, 학습용 데이터와 테스트용 데이터로 분리하여 반환하는 함수 `load_data()` 를 구현합니다.
2. - `load_iris()`를 활용해 사이킷런에 저장된 붓꽃 데이터를 불러옵니다. `return_X_y` 인자를 `True`로 설정합니다
   - 불러온 데이터를 `train_test_split()`을 활용하여 ***\*학습용 데이터(80%)와 테스트용 데이터(20%)\****로 분리합니다.
   - 일관된 결과 확인을 위해 `random_state`는 ***\*100\****으로 설정합니다.
3. 분류 의사결정 나무 모델로 학습, 예측을 수행한 후 예측 결과를 반환하는 함수`DT_Clf()`를 구현합니다.
4. - 분류를 위한의사 결정 나무 모델을 정의합니다.
   - 의사결정 나무를 학습용 데이터에 대해 학습시킵니다.
   - 테스트 데이터에 대한 분류 결과를 예측합니다.

## 3. 앙상블(Ensemble) 기법 - Voting

이번 실습에서는 다양한 앙상블 기법 중
Voting을 사용한 분류기(VotingClassifier)를 구현하는 방법을 알아보도록 하겠습니다.

### ***\*Voting\****

Voting은 의미 그대로 투표를 통해 값을 결정하는 것입니다. Voting의 종류에는 Hard voting과 Soft voting이 있습니다.

- Hard Voting : 다수의 분류기가 예측한 값을 최종값으로 선택
- Soft Voting : 각 분류기의 확률 분포를 평균 낸 후, 가장 확률값이 높은 값을 최종 값으로 선택

일반적으로 Soft voting이 성능이 더 좋아 더 많이 사용됩니다.

![image](https://cdn-api.elice.io/api-attachment/attachment/7f1f36ce2e264eddb090d6ab8e707430/Voting.png)

------

***\*VotingClassifier를 위한 사이킷런 함수/라이브러리\****

- `from sklearn.ensemble import VotingClassifier` : 사이킷런에 구현되어 있는 VotingClassifier를 불러옵니다.
- `model=VotingClassifier(estimators, voting)`: VotingClassifier 모델을 정의합니다.
- - `estimators`: 앙상블 학습을 진행할 다양한 분류 모델을 설정합니다.
  - `voting`: voting 방식을 선택합니다.
- `model.fit(X, y)`: (X, y) 데이터셋에 대해서 모델을 학습시킵니다.
- `model.predict(X)`: X 데이터에 대해 모델이 예측한 값을 반환합니다.

### ***\*실습\****

1. 다양한 모델을 사용하는 VotingClassifier를 정의하여 학습시키고, 예측을 수행한 결과를 반환하는 함수 `Voting_Clf()`를 구현합니다.

- ```
  VotingClassifier(estimators = [('모델1 이름', 모델1을 정의한 변수), ('모델2 이름', 모델2를 정의한 변수),...('모델N 이름', 모델N을 정의한 변수)], voting = 'soft')Copy
  ```

- - `estimator`와 `voting`파라미터는 아래와 같이 설정할 수 있습니다.

- - Voting과 비교할 각각 다른 분류 모델을 불러옵니다. 불러올 분류 모델은 `LogisticRegression`, `KNeighborsClassifier`입니다.
  - Voting에 사용할 분류 모델을 설정하여 `VotingClassifier`를 정의합니다.
  - `estimators`로는`'lr'`이라는 이름으로 `LogisticRegressor`인 `lr_clf`, `'knn'`이라는 이름으로 `KNeighborClassifier`인 `knn_clf`를 사용합니다.
  - Voting 방식은 `'soft'`로 지정합니다.
  - Voting Classifier를 학습용 데이터에 맞춰 학습을 시킵니다.
  - 테스트 데이터에 대한 예측을 수행합니다.

1. 실행 버튼을 눌러 앙상블 학습을 했을 때와 그렇지 않을 때의 결과가 어떻게 다른지 확인해 보세요.

## 4. 앙상블(Ensemble) 기법 - Bagging

이번 실습에서는 Bagging을 사용한 분류기(BaggingClassifier)를 구현하는 방법을 알아보도록 하겠습니다.

### ***\*배깅 (Bagging)\****

배깅(Bagging)은 여러 분류 모델을 사용했던 Voting과 달리 동일한 분류 모델만을 사용해야 합니다.

사이킷런에 구현되어 있는 BaggingClassifier를 사용해 동일한 유방암 데이터 셋을 학습, 예측해 보고 단일 의사결정 나무 모델과의 결과를 비교해 보도록 하겠습니다.

![image](https://cdn-api.elice.io/api-attachment/attachment/3ef1ae81c827411fbf83fd2d69664646/image.png)

------

***\*BaggingClassifier를 위한 사이킷런 함수/라이브러리\****

- `from sklearn.ensemble import BaggingClassifier` : 사이킷런에 구현되어 있는 BaggingClassifier를 불러옵니다.
- - `model=BaggingClassifier(base_estimator, n_estimators)` : BaggingClassifier 모델을 정의합니다.
  - `base_estimator`: 앙상블 학습을 진행할 분류 모델 설정(동일한 분류 모델)
  - `n_estimators`: 사용하고자 하는 분류 모델의 개수
- `model.fit(X, y)`: (X, y) 데이터셋에 대해서 모델을 학습시킵니다.
- `model.predict(X)`: X 데이터에 대해 모델이 예측한 값을 출력합니다.
